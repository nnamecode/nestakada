# Новый сайт автосервиса «Эстакада»

Рабочая папка: `T:\nestakada`. Исходный сайт: https://estakada-service.ru/.

Проект начат 25 октября 2026 года. Текущая точка 28 октября: BRD v0.28 утверждён по D-109; архитектура v0.6 прошла независимое ревью с закрытием AR-10–AR-22 и утверждена по D-110, затем дополнена политиками кэша, безопасности, сканеров и логов D-111–D-115. Активен этап 4б «Публичный дизайн»: требуется выбрать и согласовать новую концепцию главной, включая форму заявки; после него — этап 5 «Аналитика». Код приложения ещё не создан, продакшен-сайт не изменялся. Docker/WSL установлены, крупные данные на T:. GitHub origin и автор настроены; состояние отправки фиксируется в docs/shift-2026-10-28.md.
