## Локальный предпросмотр публичного макета

Страница `http://127.0.0.1:8765/work/public-light-v4.html` обслуживается задачей Планировщика Windows `Estakada Public Preview`. Задача использует штатный `wscript.exe` и проектный лаунчер `scripts/start-public-preview-hidden.vbs`, поэтому Python-сервер работает без консольного окна. Запуск происходит при входе текущего пользователя; контрольный минутный триггер не создаёт второй экземпляр работающего сервера и восстанавливает preview после завершения процесса.

- Зарегистрировать или обновить задачу: `powershell -ExecutionPolicy Bypass -File scripts\register-public-preview-task.ps1`.
- Удалить задачу: `powershell -ExecutionPolicy Bypass -File scripts\unregister-public-preview-task.ps1`.
- Задача слушает только `127.0.0.1:8765` и не публикует сайт в сеть.
