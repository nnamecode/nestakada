# Организация изображений нового сайта

2026-10-27. D-073/D-074. Принцип согласован владельцем; схема переноса и серверная реализация ещё впереди.

Изображения принадлежат своим разделам/материалам и хранятся в подпапках под корнем `/img/`, а не единым длинным списком. Пример владельца: `/img/articles/kuzovnoj-remont/kuzov_img_1.jpg`. Подпапки допускают несколько уровней.

Сохранённый реестр старого сайта подтверждает распределение материалов, в том числе `/assets/images/resources/articles/kuzovnoj-remont/`, другие папки `articles/<материал>/`, `/uploads/services/` и `/uploads/contacts/`. Есть также кэшированные варианты и размеры medium; переносить всю техническую структуру старой CMS буквально не требуется. Основа карты — docs/media-inventory.csv и связи страниц с файлами, а не только совпадение названий папок.

В админке у раздела/материала должна быть связанная папка медиа. При загрузке предлагается эта папка. Серверный выбор открывает её, показывает непосредственные подпапки и файлы, поддерживает переход вверх/к корню и поиск в текущей папке с подпапками. Реальный каталог ограничен настроенным корнем img и проверками доступа. Детали ручной смены папки/её имени будут уточнены в аналитике.

Макет предлагает примеры `/img/services/kuzovnoj-remont/`, `/img/articles/kuzovnoj-remont/`, `/img/contacts/`, `/img/main/`, `/img/site/` для общих ресурсов. Для услуг папка выбирается по разделу, для статей — по материалу. Это демонстрационное соответствие; полный список путей нужно сверить с реестром при переносе. Папка материала хранится как его свойство; переименование видимого заголовка не перемещает автоматически файлы.

Старые точные URL страниц сохраняются. Для картинок составляется отдельная карта исходный файл → постоянный файл/путь нового сайта → места использования. Собственные фото галереи сохраняются без изменения байтов согласно прежнему решению. Замена чужих иллюстраций новыми изображениями остаётся отдельной задачей. История страниц и Stable ссылаются на медиа; сортировка по папкам не должна перезаписывать нужные старым версиям файлы или дублировать байты в снимках. Политика конфликтов имён/перемещения используемых файлов требует аналитики.

Архив media/source-site не перемещался и не служит готовой публичной папкой img. В макете имена путей логические, примеры — сохранённые логотипы/иконки; реальной серверной загрузки/создания папок ещё нет.
