# DEV07-TP2 — простые HTML-таблицы: контракт и проверки до кода

2026-11-01. Продолжение DEV-07 после TP1 по поручению владельца «давай дальше». Основания: D-051/057/069, REQ-013/016, AC-DTL-004, dev07-format-carrier.md §5 и dev07-editor-contract.md. Применяется уже согласованный пакет Tiptap3.32.2/PM и существующий CSSOM; новых зависимостей, квот, схемы или ресурсов нет. Это HTML-таблицы внутри intro/main, не PriceV1.

## Область первого среза

Новая простая ненестированная таблица создаётся явной командой в RAM: отдельная первая строка заголовков и две строки данных, две колонки, отступ4px. Допустим последующий выбор количества через обычные операции; новые бизнес-лимиты rows/columns/cells прайса сюда не переносятся. Поддержать текст/допустимые inline marks, изменение отступа0–32px, добавление/удаление строки данных и колонки, undo/redo. Не удалять последний структурно необходимый ряд/колонку, не преобразовывать header в обычную строку автоматически; неподдержанная операция отказывается целиком без потери ввода. Перестройка ранее сохранённого заголовка не происходит при одном открытии.

Использовать принятую форму esTableBlock с tableRow children/section=head|body и typed scope, закрытые import/export. Stock table view/resize/colwidth/colgroup/style не включать: resizable:false/renderWrapper:false/View:null, собственные NodeView/renderHTML. Canonical snapshot содержит только разрешённые table/thead/tbody/tr/th/td, data-es-cellpad и исходную поддержанную семантику; private wrapper/classes/PM paragraphs без исходного p не просачиваются в wire. Любое изменение проходит прежние Check→явное принятие нормализации→Save, права/источники/receipt/stale checks не обходятся.

Сложные, nested, spanned, caption/format/section варианты вне проверяемого simple capability сохраняются как прежний opaque atom с exact server-approved source, объяснением и кнопкой HTML. Не разбирать raw input в live DOM и не выдавать fallback за completed full FMT004. Существующая таблица становится rich только при доказанном поддержанном shape; любое неподдержанное оформление/whitespace/metadata сохраняется opaque, не стирается ради promotion. Merge/split и полный legacy в этот срез не входят.

До любого stock TableMap/plugin/command обязателен bounded geometry proof; dense allocation по declared spans запрещён. Только проверенные unitspan/simple структуры получают rich capability. Общий бюджет virtual slots всех rich tables открытого field/document≤20000 с checked arithmetic; после structural candidate повторный proof до dispatch. Проверяется именно сумма, не отдельный cap каждой таблицы. Исходный HTML node/source/codepoint/depth budget действует независимо; синтетическая геометрическая проба20000slots не называется допустимым серверным HTML при превышении его реальных nodes. Неизвестный или превышающий capability shape остаётся exactopaque, а не «недопустимым содержимым по новому правилу». Автоматический fixTables не чинит импорт/transaction молча.

Padding относится только к выбранной таблице/direct cells, хранится data-es-cellpad. Render — через доверенный CSSOM/finite stylesheet без inline style. Первая header строка прозрачная, вторая строка всей таблицы затемнена, третья прозрачная и так далее без сброса на границе head/body; canonical не получает произвольных zebra цветов/classes. Активные table-padding rules входят в refresh/GC и удаляются после удаления таблицы/смены source/destroy, не копятся от прошлых документов. Одна таблица/редактор не меняет соседний или вложенный чужой стиль.

Команды используют actual DOM→PM selection того же view; вставка/структурная правка проверяет protectedShape/IDs/ordinal paths до dispatch, не сдвигает защищённое фото молча. В неподдержанном месте — объяснимый отказ до изменения. Правка сотрудника ограничена назначенными intro/main, PriceV1/owner fields не подмешиваются. Current/draft/stage остаются выбранным источником, действия RAM-only до Save; dirty/proof/epoch/unknown intent и identity cleanup прежние. Any candidate failure не оставляет частичный DOM/SQL результат и не повышает лимиты автоматически.
