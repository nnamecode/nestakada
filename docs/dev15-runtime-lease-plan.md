## Границы

Используются уже согласованные образы, сети и тома: DB512 МиБ / API256 МиБ / ingress128 МиБ, суммарно прежние 896 МиБ и 1,25 CPU. Временные операторские helper заменяют API, не добавляются поверх его ресурса. Публичных портов, Docker socket в API, новых программ/образов/томов и увеличения caps нет. Контейнеры/ключи чужих задач не трогать.

План разделён на code-gate запуска/lease и последующий конечный fault-набор. Реальный HTTP-write допускается только после проверки инструмента и exact artifact SHA. Первое исполнение не означает PASS всех RP15-013–019: отдельные нагрузочные/SQL-injection/TLS-negative/recovery controls остаются в реестре до фактического выполнения. APP, DEV-29, внешний ARC-10/площадка, старый сайт/VPS и production не входят.

Постоянные RL15-ID сохраняются. Ошибки/attempts/UNKNOWN сохраняются; второй эквивалентный отказ без новых свидетельств немедленно останавливает работу по AGENTS.md до решения владельца.
