# DEV-29: локальное создание неопубликованных страниц — результат

2026-11-03, D-408/D-409, CP29-001–012. **Backend и HTTP PASS; [независимое итоговое ревью принято](dev29-create-implementation-review.md).** DEV-29 около 30%, этап 8 около 31%.

Реализованы пять согласованных типов: услуга, статья, каталог услуг, обзор раздела услуг и каталог статей. Владелец проверяет полный URL до сохранения; H1/title предложены один раз и редактируются отдельно. Page, PRIMARY, начальная версия/метаданные/current, OwnerDraft/base pin, минимальная квитанция и аудит создаются одной транзакцией. Ошибка откатывает весь состав; точный повтор не создаёт дубль и не восстанавливает позднее удалённую страницу.

После создания открывается фактический OwnerDraft. При повторе берётся его актуальная revision, без возврата старого содержимого или автоматического rebase. Первое code-review нашло переход в current вместо draft; замечание исправлено до запуска. Тесты проверяют настоящий editor check→draft→save для каждого типа. Новая страница остаётся неопубликованной при сохранении содержимого.

## Сохранённый первый FAIL

Первый прогон:211 тестов/222,098 с,16 failed assertions (включая подслучаи). Десять старых audit/accounts assertions нулевого состояния увидели синтетические ledger/throttle от прошлого UNIT HTTP-прогона. Обычная очистка TransactionTestCase завершила тестовый цикл; отдельное read-only наблюдение подтвердило нули AuditEvent/LoginThrottle/User/Page/OperationReceipt. Ручной flush ради допуска не выполнялся. Эта БД — существующая тестовая UNIT; не выдаём её содержимое перед backend-suite за сохранённое после штатного тестового lifecycle. MAIN backend-тестами не использовалась.

Остальные отказы: новый тестовый клиент по умолчанию не проверял CSRF; в draft-запросе отсутствовал обязательный `rebase:false`. Исправлены только тестовый клиент и draft DTO в тесте/HTTP-инструменте, не продуктовая авторизация. Изменённые условия и code/QA-gate независимо проверены перед повтором; исходный FAIL сохранён. На ревью helper также исправлена каноническая ссылка `uuid:<PageID>` при подсчёте аудита, до реального HTTP-запуска.
