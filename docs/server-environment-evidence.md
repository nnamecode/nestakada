## Следствия для этапа 7

В отличие от обычного shared-hosting VPS потенциально позволяет разместить Django/PostgreSQL/прокси и отдельные процессы. Наличие root/возможности настройки firewall/томов/надзора, выбранных версий и достаточных ресурсов пока не проверено; конкретную схему нельзя объявить совместимой только по KVM/объёмуRAM.

CentOS Linux7 завершил обычную поддержку30июня2024; проект больше не публикует для него обновления. Основание: [официальное сообщение CentOS](https://blog.centos.org/2023/04/end-dates-are-coming-for-centos-stream-8-and-centos-linux-7/), проверено2026-10-30. Наличие стороннего extended-support на данном сервере неизвестно. Контейнер не заменяет обновляемую ОС/ядро хоста. Для нового развёртывания требуется отдельно предложить/согласовать поддерживаемую среду; не трактовать это как разрешение переустановить существующий VPS.

4ядра/8ГБ — подходящая исходная конфигурация для подготовки схемы небольшого проекта, а не доказательство прохождения PERF-NORMAL/SCAN/MIXED/FAILURE. Испытания идут на изолированном стенде, не на действующем сервере.80ГБ общего диска не равны80ГБ свободного места под сайт; ОС, текущие сайты/БД, логи,2локальные полные точки,2HTML+временный третий и рабочие файлы учитываются отдельно.7внешних точек и независимый head/наблюдатель требуют собственных проверок READY-02/03.

## TEST-Q003 — назначение существующего VPS

Закрыт 2026-10-30 по D-305: на VPS работает старый сайт «Эстакады». Владелец прямо запретил его трогать и сообщил, что сам удалит старые файлы для будущей загрузки в пустой каталог. Повторно назначение VPS не спрашивать. Агент не удаляет/перезаписывает старые файлы/БД, не меняет ОС/настройки и не использует действующий сервер как тестовый стенд.

Самостоятельное удаление владельцем — намерение на будущее, а не уже выполненное действие. Перед будущим переносом остаются проверенная резервная копия/откат и отдельное разрешение RELEASE-02. Поддерживаемая серверная среда прорабатывается отдельным предложением без действий на VPS: освобождение веб-каталога не является переустановкой ОС и не подтверждает готовность Django/PostgreSQL/прокси. Сейчас локально продолжается этап 7; разрешения загружать новый сайт нет.

Далее ARC-09 готовит конкретную схему без изменения сервера, ARC-10 независимо проверяет её и передаёт владельцу на согласование. Текущий этап7 продолжается; код сайта и production не разрешены.
