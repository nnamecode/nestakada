# Приёмочные сценарии адаптивной главной

Статус: согласованный рабочий набор для D-145 и UX-05. Проверяется локальный макет `work/public-light-v4.html`; живой сайт не изменяется.

## Матрица ширин

- 320 px — минимальный поддерживаемый телефон.
- 390 px — современный телефон.
- 768 px — планшет в портретной ориентации.
- 1024 px — планшет/небольшой ноутбук.
- 1440 px и шире — контроль сохранности утверждённого десктопа.

## Сценарии

| ID | Сценарий | Ожидаемый результат |
|---|---|---|
| RSP-AC-01 | Открыть главную на каждой ширине | Нет горизонтальной прокрутки, обрезанного текста и наложений; порядок блоков соответствует десктопу |
| RSP-AC-02 | Проверить шапку на 320/390/768 | Логотип и кнопка меню видны; меню открывается, ссылки доступны для касания, после перехода закрывается; контакты не ломают шапку |
| RSP-AC-03 | Просмотреть первый экран | Заголовок, описание и ключевая часть фотографии читаются; панель не закрывает смысловой центр изображения |
| RSP-AC-04 | Просмотреть преимущества, сравнение и процесс | Карточки идут в читаемом порядке, текст не переполняет карточки, элементы не становятся чрезмерно высокими или мелкими |
| RSP-AC-05 | Просмотреть услуги, прайс, работы и отзывы | Карточки и переключатели пригодны для касания; изображения не искажены; горизонтальные ленты явно прокручиваются либо перестраиваются в сетку |
| RSP-AC-06 | Просмотреть фотополосу | На планшетах и телефонах используется статичное позиционирование без fixed/parallax; фотография не дёргается и сохраняет осмысленный кадр |
| RSP-AC-07 | Просмотреть заявку, контакты и карту | Поля не выходят за экран, подписи читаемы, кнопка и ссылки имеют достаточную высоту, карта не вызывает горизонтальное переполнение |
| RSP-AC-08 | Проверить футер | Логотип, копирайт и юридические подписи читаются и переносятся без наложений |
| RSP-AC-09 | Проверить клавиатуру и доступность | Фокус видим, меню сообщает состояние, изображения сохраняют alt, интерактивные элементы доступны последовательно |
| RSP-AC-10 | Повторно открыть широкий десктоп | Утверждённая по D-145 композиция и размеры десктопа не изменились |

## Результат проверки 2026-10-29

- RSP-AC-01: на 320, 390, 768 и 1024 px горизонтального переполнения нет.
- RSP-AC-02: мобильное меню открывается, сообщает состояние и сохраняет доступ к навигации.
- RSP-AC-03–RSP-AC-08: блоки перестроены для телефона и планшета; контакты, карта, форма, изображения и футер укладываются в экран.
- RSP-AC-05: вкладки прайса переключаются; активна ровно одна панель.
- RSP-AC-06: на ширинах до 800 px фотополоса статична, тяжёлый десктопный эффект отключён.
- RSP-AC-09: сохранены заголовки, alt-тексты, состояния меню и последовательные интерактивные элементы.
- RSP-AC-10: контрольная ширина 1024 px и широкий десктоп используют прежнюю утверждённую композицию.

Техническая проверка пройдена. Визуальный результат утверждён владельцем 2026-10-29 по D-146; живой сайт не изменялся.
