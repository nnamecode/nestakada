# Границы редакторского ввода: частичные AT-101/103

2026-10-30. Основания: принятые TECH-01/ANA по D-301, D-302/D-308. Только приёмочные утверждения; код приложения, старый сайт и VPS не меняются.

`acceptance/editor-boundaries.spec.js`:14 экземпляров. Девять проверяют H1/title254/255/256 и description999/1000/1001 на прямом запросе владельца; одна — пустое description без автоподстановки; две — сохранение SEO при правке основного текста владельцем/сотрудником. Ещё две проверяют отклонение изначально разрешённой правки прайса после смены редакции либо отзыва отдельного права. До отказа сотрудник успешно правит тот же прайс; после отказа значение принимает владелец со свежим основанием.

Транспорт использует действующий профиль `assigned-page-with-owner-draft`, `page`, `submit-page-direct`, `save-text`, `edit-price`, `grant-price`. Дополнительный `revoke-price` — настоящий явный UI/HTTP-запрос владельца на снятие отдельного права прайса, не изменение SQL через наблюдателя. Остальные права страницы сохраняются. Имена — контракт теста, не выбранные URL/ORM/endpoint продукта.

Границы берутся из таблицы полей TECH-01, принятой в составе D-301. Проверяются кириллические BMP-символы; способ подсчёта astral/составных Unicode отдельно не придумывается. Прямой запрос не обрезается драйвером, не подменяется браузерным maxlength. Отказ обязан оставить опубликованные данные, SEO, черновик и историю без частичного изменения; отдельный аудит отказа допустим. Снимок `page` берётся из фактического закрытого чтения SQL будущего изолированного приложения, а не из отправленного payload.

Остаток: старые длинные значения/миграция, метатег после пустого description, предупреждения/подсказки UI, вся санитаризация/Unicode, совместное текст+прайс сохранение, конкурентный отзыв в середине commit, прочие ветви AT-101/103. Нет приложения/bindings/bridge; эти сценарии не исполнялись. Успешная сборка и самопроверки инструмента не означают прохождение AC.
