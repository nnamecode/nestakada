Реальные HTTP evidence создаются на штатном local_http/main URLConf/Nginx, без нового публичного диагностического API. Pure/framework positive passthrough и реальный public200 — разные доказательства; public renderer всё ещё DEV08, full TEST08 binding/TEST09 остаются отдельными. Если runtime observer не видит process-local counters другого PID, не выдавать0 за отсутствие сканов: exact counter свойства доказать в реальном middleware process/framework, native ресурс/log/DB границу отдельно.

Производительность unit: фиксированный adversarial corpus/число шагов и практическое измерение, не хрупкий абсолютный microbenchmark по wallclock. Запрещены реальные внешние цели/настоящие ПД и увеличение лимитов ради PASS. Неудача получает конкретный finding; повтор того же действия без нового условия следует AGENTS stop rule.
