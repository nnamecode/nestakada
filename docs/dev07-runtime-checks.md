# DEV-07 — сценарии runtime guard до кода

2026-10-31, D-331, V07-004/008/011/015. Это unit/socket/process сценарии ограниченного механизма; они не подменяют последующую настоящую Nginx/Django проверку ранних прав/CSRF/HTTP framing и всего editor pipeline.

| ID | Заранее заданное ожидание |
|---|---|
| R07-001 | Профили из серверных owner/price/shared прав дают только64/5/4МиБ; неверные типы и shared без owner отвергаются |
| R07-002 | Настоящий socket stream принимает ровно допустимые bytes и границу; превышение Content-Length отклоняется до чтения, счётчик не доверяет одному заголовку |
| R07-003 | Неоднозначная/отсутствующая/отрицательная/нечисловая длина, transfer-encoding и неправильный content-type не принимаются. Обрыв до обещанной длины даёт отказ без подстановки частичного ввода |
| R07-004 | Реальный блокирующий read на частично переданном теле прекращается по короткому тестовому deadline, а не только после следующего байта. Завершённый read не оставляет таймер, способный закрыть последующее соединение |
| R07-005 | Без пригодного WSGI socket механизм не объявляет абсолютный timeout обеспеченным. Неизвестный транспорт отклоняется, а не молча получает неограниченный read |
| R07-006 | Два независимых fd/процесса не занимают slot одновременно; busy не ждёт. После исключения слот доступен; symlink/hardlink/чужой или слишком открытый lock-file запрещён; файл не unlink-ится при обычном release |
| R07-007 | Успешный child получает ровно фиксированную framed context+raw структуру и возвращает валидный bounded JSON. Большие одновременные stdin/stdout/stderr не создают pipe deadlock |
| R07-008 | Wall deadline охватывает передачу stdin, чтение stdout/stderr и exit; зависший/нечитающий child завершается kill/reap, без оставшегося процесса |
| R07-009 | Output cap и stderr cap останавливают генератор без хранения/логирования сырой диагностики. Неожиданный exit/JSON/protocol/duplicate keys/NaN дают фиксированный отказ, не ложный успех |
| R07-010 | Окружение и наследуемый специально открытый fd не попадают ребёнку; command/filename не берутся из body/context. Временный test canary не выводится в лог |
| R07-011 | В настоящем subprocess configure_limits задаёт AS384МиБ/CPU10с/core0; память за пределом получает контролируемый отказ. Не применяется небезопасный preexec_fn в многопоточном приложении |
| R07-012 | Bootstrap использует статический путь политики, строгую рамку/размеры и bounded результат; отсутствие ещё не подключённого producer не вызывает произвольную команду или fallback |

До handler admission дополнительно обязательны V07, actual64MiB/полный canonical maximum, parent+child peak/CPU, настоящий Nginx early401/403/CSRF, framing/slow/abort, повторная проверка доменных прав и отсутствие SQL locks во время upload/parse. Продуктовый timeout прекращения чтения требует code review и actual socket доказательства. Новые зависимости/службы/порты не вводятся; старый сайт/VPS не используются.
