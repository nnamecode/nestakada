## Предусловия

ESTAKADA_TEST_BASE_URL указывает только на изолированный стенд по правилам test-support.js. Нужен обычный режим Django, а не аварийный HTML, и импортированная fixture опубликованных материалов; для canonical-сценариев соответствующие материалы разрешены к индексации. Доверенный origin тестовой конфигурации совпадает с явным origin стенда. Работоспособность/идентичность приложения и состояние fixture подтверждаются отдельно; HTTP200 или наличие canonical сами по себе этого не доказывают.

Если target не задан, файл получает явный NOT RUN без запросов к preview/живому сайту и без открытия приложения. Это не закрывает ни один AC. Имеющийся ENV-HTTP-001 в другом файле сохраняет первоначальный красный результат до задания изолированного target.

HTTP выполняется только getLocal, с запретом внешнего origin/Location и без автоматического следования redirect, кроме сохранённой цепочки page=1. DOMParser разбирает фактически полученный HTTP HTML в инертном документе внутри пустой браузерной страницы: полученный HTML не передаётся setContent, JS страницы отключён, все браузерные network-запросы прерываются. Это разбор ответа, а не макет/подмена будущего приложения. Выполнение JS сайта/гидратация/интеграции этим не проверяются.
