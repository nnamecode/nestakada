# Передача работы: внутренние публичные страницы

Статус: стартовая точка UX-06, этап 4б. Главная v4 для десктопа, планшета и телефона утверждена владельцем 2026-10-29 по D-145/D-146.

## Что сохраняется

- Визуальная система утверждённой главной: белый и светло-серый фон, чёрная и оранжевая типографика, компактная композиция, фирменная шапка, контакты и футер.
- Точные адреса и структура старого рекламируемого сайта по D-023.
- Собственные фотографии работ из `/gallery-of-works/` переносятся побайтно без изменений по D-024.
- Остальные иллюстрации создаются заново по смыслу услуги по D-025.
- Для каждой страницы услуги нужна индивидуальная объясняющая инфографика по D-086.
- Сначала прорабатывается полноценный десктоп страницы, после согласования — планшет и телефон по принципу D-119.
- Живой сайт не изменяется без отдельного разрешения.

## Первый шаг нового чата

1. Прочитать `README.md`, `docs/decisions.md`, `docs/tasks.md`, `docs/pipeline.md` и этот документ.
2. По старой структуре определить типы внутренних страниц и выбрать одну первую страницу для эталонного макета.
3. Зафиксировать её точный действующий URL, исходные тексты, фотографии и обязательные блоки.
4. Подготовить десктопный макет в визуальной системе главной; не начинать адаптив до согласования композиции.
