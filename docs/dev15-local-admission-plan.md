Первый исполняемый инкремент ограничен AD15-001–005/008: Inspect → Prepare → Activate/точный Retry → Stop. Он не выпускает run lease и не включает HTTP-запись. AD15-006–007 остаются отдельными незавершёнными фазами; это позволяет проверить сохранность политического перехода до допуска запросов.

Реализация — новые локальные операторские инструменты в tools; временный Compose override только добавляет read-only bind принятого пакета к существующему migrator-сервису. DB 512 МиБ + tool 256 МиБ; API/ingress во время оператора остановлены. Установки программ, image pull, публичных портов, нового тома и увеличения лимитов нет. Новый инструмент конкретизирует согласованный операторский переход D-380. При новой архитектуре или несовместимости — остановка и отдельное предложение владельцу.

Независимая сверка плана приняла разделение фаз и выявила два обязательных ограничения реализации. Первый инкремент использует только DB/tool и существующие env/frozen source: обычный local Start/Stop не вызывается, исходный runtime/manifest.json входит в 63 provenance-входа и должен остаться побайтно прежним. Состояние нового перехода сохраняется отдельно. Старый archive verifier, ожидающий MAIN Head9/policy0, после commit не является проверкой новой MAIN: отдельно подтверждаются неизменность архивов и прежних строк/pin, а также только разрешённый delta Head/policy/receipt. Исторические квитанции не переписываются, guard не отключается. Для будущего lease исторические байты runtime должны быть сохранены до разрешённой смены его metadata и явно связаны с новым состоянием.

Ошибки и попытки сохраняются. При первой ошибке сообщить причину; второй эквивалентный повтор без новых данных запрещает продолжение до решения владельца по AGENTS.md. Существующие retention/Tests/Calibrate не запускать, корпуса не очищать.
