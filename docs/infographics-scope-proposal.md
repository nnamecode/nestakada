# INFOGRAPHICS-01: минимальная граница первой очереди

Статус: **предложение на согласование; изображения и продуктовый код не создавались**.

Дата: 2026-11-13. Основание: D-086, D-025, MEDIA-06 и canonical DEV-09M D-961.

## Цель

Для каждой внутренней страницы услуги нужна индивидуальная объясняющая инфографика: какие проблемы связаны с услугой, почему требуется проверка или ремонт и какой результат работы понятен клиенту. Это дополнение к сохранённому тексту, а не рерайт и не рекламное обещание.

## Минимальная первая очередь

Первая очередь ограничена exact24 страницами DEV-09M. Это отдельный проверяемый срез, а не объявление всей INFOGRAPHICS-01 завершённой. Остальные внутренние страницы услуг добавляются последующими группами только по уже согласованному формату.

После утверждения образца для каждой из 24 страниц готовится ровно один самостоятельный растровый файл в принятом формате:

- общий спокойный визуальный язык сайта, но индивидуальный смысл услуги;
- не более трёх коротких смысловых пунктов, чтобы изображение читалось на телефоне;
- один исходный файл без desktop/mobile дублей; необходимость другого варианта можно доказать только проверкой образца в будущем согласованном placement;
- для первого образца MAP-019 кандидатные параметры: WebP, 4:3, 1200×900, не более 1 000 000 байт; они не фиксируют параметры остальных файлов до `INFO-Q002`;
- без логотипов производителей, чужих фотографий, цен, сроков, гарантий результата и неподтверждённых диагностических утверждений;
- отдельный точный alt-текст и краткая подпись под изображением; важный смысл не должен быть доступен только из текста внутри растра.

`MAP-115` входит в инфографическую очередь как самостоятельная страница услуги. Его отложенный hero из D-963 не требует расширения hero. Конкретное место размещения инфографики для MAP-115 и остальных страниц определяется отдельным будущим design/import gate; этот документ не утверждает новый slot или renderer branch.

## Порядок без массовой переделки

1. Подготовить текстовую карту exact24: для каждого MAP — заголовок, до трёх проверяемых смысловых пунктов, alt и подпись. Не генерировать изображения.
2. Независимо проверить технический смысл и отсутствие обещаний/подмены диагностики.
3. Сделать один образец для `MAP-019 Ремонт кузова` с кандидатными параметрами WebP 4:3, 1200×900, ≤1 000 000 байт.
4. Проверить образец в будущем согласованном placement на desktop/mobile и представить владельцу композицию, читаемость, фактический формат, размеры и byte cap.
5. Только отдельный ответ владельца `INFO-Q002=1` фиксирует итоговые параметры и разрешает выпуск остальных 23 файлов; каждый файл затем сверяется с принятой картой.

Такой порядок ограничивает стоимость ошибки одним образцом и не создаёт universal infographic builder.

## Не создавать

- новую модель/таблицу, API, JavaScript-компонент, редактор схем, шаблонизатор или генерацию на сервере;
- SVG/HTML с исполняемым либо произвольным содержимым;
- отдельные desktop/tablet/mobile файлы без доказанной необходимости;
- медицинские/страховые аналогии, устрашающие формулировки и абсолютные обещания;
- импорт в Asset/БД, привязку к версиям, публикацию или действия на live/VPS до отдельных gates.
- изменение DEV-09M grammar/renderer или новый media-slot до отдельного плана и согласования интеграции.

## Приёмка первой очереди

- `INFO-AT-001`: карта содержит ровно 24 canonical MAP без дублей и пропусков.
- `INFO-AT-002`: каждый набор индивидуален по смыслу услуги и не противоречит сохранённому тексту страницы.
- `INFO-AT-003`: MAP-019 проверяется с кандидатными WebP/4:3/1200×900/≤1 000 000 байт; exact формат, размеры и byte cap партии фиксируются только `INFO-Q002` после desktop/mobile проверки образца. Финальная партия содержит exact24 уникальных файла с локальными SHA-256 и без неутверждённых вариантов.
- `INFO-AT-004`: подпись и alt не содержат цен/сроков/гарантий и передают смысл без зависимости от мелкого raster-текста.
- `INFO-AT-005`: один образец MAP-019 отдельно принят владельцем до пакетного выпуска остальных 23.
- `INFO-AT-006`: генерация не меняет gallery originals, продуктовый код, БД, foundation, Git binary scope, публикацию или live.

## Owner gate

`INFO-Q001=1` — принять минимальный порядок: сначала текстовая карта24 и независимая проверка, затем один образец MAP-019; без массовой генерации до отдельного просмотра владельцем.

`INFO-Q001=2` — предложить другой первый MAP или формат до подготовки карты. Изображения до ответа не создаются.

Будущий gate после образца: `INFO-Q002=1` — принять композицию MAP-019, зафиксировать доказанные placement/формат/размеры/byte cap и разрешить остальные 23 файла; `INFO-Q002=2` — вернуть только образец на корректировку. Без `INFO-Q002=1` пакетная генерация запрещена.
