## Исправления и история отказов

Первый Start до создания контейнеров зациклился из-за PowerShell Docker→docker; процесс остановлен и задача приостановлена по AGENTS. Возобновление явно разрешено D-317. Теперь вызов docker.exe явный, массив аргументов передаётся раздельно. При повторном старте исправлена работа с DACL без запроса SeSecurityPrivilege. При первом dev init зафиксирована гонка: временный socket-only PostgreSQL уже отвечал pg_isready, конечный TCP ещё не был поднят; теперь readiness явно проверяет TCP 127.0.0.1:5432. Исправленные старты и миграции прошли. Эквивалентные слепые повторы не выполнялись.

Ревью устранило DEV-REV-001–005: сырые Nginx error logs, свободный IPv6 zone suffix, смену свидетельств между сбором/приёмкой, перезапись AuditEvent через новый ORM-объект с заданным PK, потерю порта Host при проксировании. В модели теперь только INSERT; QuerySet/raw SQL не объявляются неизменяемым хранилищем. Ротация, квоты, очистка и полные диагностические коды — последующие модули.
