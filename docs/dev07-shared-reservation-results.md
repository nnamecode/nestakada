## Реализация

Журнал связан с owner Draft/Apply/Restore prepare. Единая неблокирующая PostgreSQL session lease сериализует admission, запись и reconciliation; файловые операции выполняются вне тяжёлой SQL-транзакции. Immutable HTML, metadata, постоянные identities, media refs/pins, receipt и audit согласованы через короткую атомарную фазу. Миграция0004 добавляет сведения результата/резервирования и retained debt;0001–0003 не переписывались.

Повтор той же операции возвращает прежний результат без второй версии. Известный commit подтверждается receipt, доказанный abort — отдельным terminal receipt; неопределённый исход сохраняет бронь. Отсутствие receipt после перезапуска само по себе не доказывает откат. Ошибка измерения закрывает дальнейшую запись; расход файлов и PostgreSQL после rollback не исчезает из учёта.

Интерфейс сохраняет неопределённое намерение и новый ввод в RAM. Ручной повтор отправляет прежние данные с прежним operationId. Подтверждение старой отправки не отмечает последующий текст сохранённым. HTML не помещается в Web Storage или URL; окончание сессии не очищает ввод.
