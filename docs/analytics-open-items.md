## 1. Закрытый стык ANA-Q058

### ANA-Q058 — зависимое содержимое старого HTML после скрытия/удаления услуги

**Закрыт 2026-10-30, D-300.** Удаление раздела не переделывает настроенную главную; владелец проверяет/правит её отдельно. Допустима обычная главная последней ночной копии со старыми публичными элементами, без подмены контактной страницей только из-за удалённой ссылки. Собственные скрытые/удалённые адреса не воскресают. Связи: D-256 с уточнением D-300, D-280/D-281, D-283, D-295; REQ-002/REQ-012/REQ-046/REQ-047. [Технический документ и история вариантов](analytics-html-reserve.md).

Основание ответа: владелец сам проверяет и вручную либо с помощью агента редактирует главную после удаления. В аварии её ночной публичный вид допустим. Действующий опубликованный прайс продолжает обновлять связанную сумму; автоматическое скрытие из-за удалённого источника заменено ручной проверкой главной. Обычное снятие источника с публикации без удаления отдельно не отменяет D-256.

**Что не пересогласовываем:** только ночные сборки; две исправные копии; допустимая обычная устарелость цен; отсутствие публичного сообщения о сбое. Это уже принято. Не вводить новый возраст снимка или срок действий владельца.

**Оставшаяся техническая работа:** отдельный допуск собственных маршрутов при отказавшей БД, безопасный предварительный запрет, неизвестный коммит, свежесть после отката и граница допуска ответа. Граф ссылок не должен транзитивно выключать главную из-за допустимых старых публичных элементов D-300. Предложение не обещает атомарности PostgreSQL/файлов и ещё требует итогового ревью.

Исторические варианты сохранены в HTML-документе. Вариант 1 с исчезновением полноценной главной не принят; механизм точечной дневной переделки по варианту 2 не заказан. Ответ владельца зафиксирован отдельно как ANA-A058/D-300, его нельзя подменять прежней рекомендацией.

## 4. Что не является открытым вопросом

- Интервал мониторинга пять минут, две неудачи/два успеха уже выбраны; кандидат сервиса не меняет правило.
- Владелец не обязан реагировать/восстанавливать за четыре или двадцать четыре часа. Восстановление вручную по его решению; автоматические копии и уведомления сохраняются.
- Stable ставит и снимает только `nesadmin`, снятие с подтверждением/паролем; отдельное удаление защищённой версии не вводится.
- Заявки автоматически не удаляются; владелец имеет защищённое ручное удаление; правовая политика ещё отдельно.
- HTML — только ночью, две исправные копии, без сообщения посетителям о сбое, возврат автоматический после двух успехов, форма не заявляет ложного приёма.
- Сотрудник не управляет своим паролем, текстами главной, SEO/URL/медиа; обычные ссылки в назначенном тексте допустимы.
- Семь внешних и две локальные точки БД/медиа не заменены двумя HTML-наборами; никакое новое расписание/автоматизация сейчас не создаётся.
