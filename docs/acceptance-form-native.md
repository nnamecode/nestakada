# Обычная HTML-форма без JavaScript и CSRF

2026-10-30. D-301/302/303/305/308; PR-01 analytics-protocol-contracts.md, AT-401/404, AC-PRO-001/004. Только тесты этапа7, без сайта/миграций/конфигурации продукта или изменений старого сайта/VPS.

`acceptance/form-native.spec.js`: 8 экземпляров, по4 для home/contacts. Настоящий actor Chromium создаётся с `javaScriptEnabled:false`, serviceWorkers:block; это отдельный параметр openApplicationDriver, а не отключение JS только в парсере. Самопроверка DRIVER-SAFE-029 проверяет эти же параметры на синтетическом транспортном HTML: inline-script не выполняется, native POST доходит до перехватчика без сети. Она не проверяет приложение.

## Привязки будущего приложения

Профиль `isolated-form-with-local-sinks` существующий. VISITOR — отдельный посетитель с синтетическими данными; Telegram/аналитика только локальные sinks. Никаких реальных отправок и открытия LEGAL-ворот.

- `open-native-form(source)` — **UI goto** реальной главной/контактов. result HTML accepted200 с действительным маркером формы; из реальных атрибутов/успешно отправляемых элементов формы извлекаются formMethod, csrfToken/signedIntent, context. Секретные поля помечаются `secret:true`, не пишутся в артефакты. Версия согласия может находиться внутри signed intent: отдельное hidden-поле не требуется. После принятия проверяется непустая сохранённая version из `form-consent-evidence` и её связь с той же request. context — непрозрачная ссылка на фактически выданное представление для private observation, не публичный ID заявки. Один goto не включает POST, фоновые бизнес-вызовы или получение фиктивного CSRF.
- `submit-native-form(source,payload)` — только UI fill/check/click штатной HTML-кнопки. Browser сам отправляет hidden поля и cookies. Никакого evaluate/request.fetch/request.post/переписывания токенов. Выход accepted только по действительному серверному результату, не по200. При PRG binding ждёт конечную navigation GET и её маркер результата; промежуточный redirect/GET формы не считается успехом. Заполнение не повторно открывает форму и не подменяет исходный intent. Реальная структура/селекторы/пути появятся с приложением и проходят отдельное ревью.
- `submit-form-without-csrf`/`submit-form-corrupt-csrf(source,context,payload)` — реальные прямые form POST с **тем же** валидным signed intent, cookie и согласованными полями; первая операция пропускает CSRF field/header, вторая меняет только submitted CSRF. Не отключает middleware и не меняет cookie. Ответ denied имеет private,no-store. После отказа исходная открытая браузерная форма успешно отправляется; отдельная проба повторяет corrupt-CSRF после реального принятия того же intent и проверяет отсутствие обхода через receipt.
- `form-counters`, `form-intent-records`, `request-by-id` — существующие read-only actual-db наблюдения. Положительная запись связывается с исходным intent, проверяется собственный введённый текст; приватный ID не извлекается из публичного ответа.
- `form-allocation-counters` — actual-db `{receipts,visitorDbSessions}` по изолированному run, включая реально создаваемые записи посетительских сессий, а не только request. До/после GET и отвергнутого POST точное равенство. Подготовка ничего не создаёт заранее ради прохождения проверки.

Перед сменой схемы каждого binding нужен независимый просмотр его фактического UI/HTTP/DB источника. Объявление source не доказывает происхождение данных само по себе.

## Пределы

Эти8 сценариев не запускались: приложения/fixture bridge/bindings нет. Успех тестового инструмента и сборки списка не является прохождением AC. Исключение действующих токенов из ночного HTML уже частично проверяется html-build/fallback; все cookie/privacy/LEGAL, маскирование всех выходов, ошибки в открытом DOM/обновление CSRF при ротации, точные границы времени и полный AC остаются отдельными ветвями. Старые FORM-WINDOW-* проверки AT-403/404 сохраняются.

Не требуем обязательной JS-цели Метрики при отключённом JS: допустимый прирост acceptedGoals0–1, ни одной второй заявки/согласия и никаких внешних сообщений. Самопроверки инструмента отдельно от приёмки сайта.
