- D-114/D-115 утвердили кодовую защиту от массовых сканеров и журнальный предел: ранний Django-фильтр до сессии/БД, настоящие лёгкие 404, агрегирование шума, Telegram без шторма, проверки известных PHP/WordPress/.env/.git-путей. Управляемая папка логов имеет единый предел 1 ГиБ без квот категорий; бэкапы хранятся отдельно. Основа — docs/scanner-defense.md.

## Хранение и GitHub

В Git отправляются документы, текстовые реестры и разрешённые шаблоны/скрипты. Оригиналы фотографий, локальные архивы старого сайта, рабочие предпросмотры, логи, дампы, секреты и пользовательские данные в Git не добавляются. `media/source-site`, `media/design-concepts`, `work` и другие крупные локальные материалы остаются на T: и исключены из репозитория.

Отправка выполняется в `main` репозитория https://github.com/nnamecode/nestakada после проверок конца смены. Для Git используется точечный `-c safe.directory=T:/nestakada`; глобальная конфигурация не меняется.

## Проверки конца смены

- Проверить Markdown/пробелы через `git diff --check`.
- Проверить отсутствие секретов, пользовательских данных, логов, дампов и крупных случайных файлов в индексе.
- Проверить согласованность README, docs/pipeline.md, docs/tasks.md, docs/decisions.md и документов архитектуры.
- После push сверить локальный HEAD с `origin/main` и чистоту рабочего дерева.

Продуктовые тесты отсутствуют, поскольку приложение ещё не создано; выполненные проверки относятся к документации и состоянию Git.
